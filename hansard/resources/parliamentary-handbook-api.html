Parliamentary Handbook API

Author

Tim Sherratt 

import textwrap

import altair as alt
import pandas as pd
import requests

The Parliamentary Handbook includes a simple API that you can use to get the data about parliament and parliamentarians in machine-readable form.

Parliamentarians

Aggregated data about individuals can be accessed via: https://handbookapi.aph.gov.au/api/individuals/. However, this data only includes a summary of the available information for each person. There are a variety of other endpoints that can be used to access the full data. For example:

description endpoint parameters
records of service, includes parliamentary terms, committee membership etc recordsofservice ?filter=PHID eq '[PH ID]'
party membership PartiesData/GetPartyServiceForParliamentarian ?personId=[PHID]
timeline of Parliamentary and Party service Parliamentarian/GetTimeline ?id=[PHID]
biography Parliamentarian/GetBiography ?id=[PHID]
speeches Parliamentarian/GetSpeeches ?Id=[PHID]
Ministerial Statements Parliamentarian/GetMinisterialStatements ?Id=[PHID]
committee service CommitteeServiceRecords/BiographyService/[PHID]

Ministries

According to the APH Glossary, a ministry comprises:

members from both houses of Parliament chosen from the party or coalition of parties with a majority in the lower house to administer the country, who are formally appointed by the Governor-General as his or her ministers of state and together with the Governor-General form the executive government

A government can have multiple ministries across its lifetime as personnel and portfolios are re-arranged.

To retrieve the dates of each ministry and shadow ministry, you can use the following API endpoints:

  • Ministries – https://handbookapi.aph.gov.au/api/ministries
  • Shadow Ministries – https://handbookapi.aph.gov.au/api/shadowministries

These endpoints return a list of ministries, with records of the form:

    MIDOrdinal: "3rd",

  • Shadow Ministries – https://handbookapi.aph.gov.au/api/StatisticalInformation/ShadowMinistries

Examples

Gender breakdown of ministries.

df_min = pd.read_json(
    "https://handbookapi.aph.gov.au/api/StatisticalInformation/Ministries"
)
# Separate numbers for men and women
df_min["men"] = df_min["Ministers"] - df_min["WomenMinisters"]
df_min.rename(columns={"WomenMinisters": "women"}, inplace=True)
# Convert to long-form data for Altair
df_min_gender = df_min[["Id", "MinistryName", "women", "men"]].melt(
    ["Id", "MinistryName"], var_name="gender", value_name="number"
)
min_gender_chart = (
    alt.Chart(df_min_gender)
    .mark_bar()
    .encode(
        x=alt.X("MinistryName:N").sort(field="Id").title(None),
        y="number:Q",
        color="gender:N",
        tooltip=["gender:N", "number:Q"],
    )
    .properties(width="container", padding=20)
)

Create a list of governments

The Handbook has lists of PMs and Ministries, but not lists of governments – ie the combination of a particular PM leading a particular party in government for an unbroken period of time.

Simplifies party to “Labor” and “non-Labor”.

df_min = pd.read_json(
    "https://handbookapi.aph.gov.au/api/StatisticalInformation/Ministries",
    convert_dates=["DateStart", "DateEnd"],
)
df_min["parties"] = df_min.apply(
    lambda x: " | ".join(sorted([p["Name"] for p in x["Parties"]])), axis=1
)
df_min["party"] = df_min.apply(
    lambda x: "Labor" if "Australian Labor Party" in x["parties"] else "Non-Labor",
    axis=1,
)
pm_data = requests.get(
    "https://handbookapi.aph.gov.au/api/HistoricalInformation/PrimeMinisters"
).json()
pms = {pm["Phid"]: pm for pm in pm_data}
governments = []
current_pm = ""
current_party = ""
current_end = ""

for mini in df_min.sort_values("Id", ascending=True).itertuples():
    if mini.LeaderPHID != current_pm or mini.party != current_party:
        if current_end:
            governments[-1]["end_date"] = current_end
        current_end = mini.DateEnd.date().isoformat()
        current_party = mini.party
        current_pm = mini.LeaderPHID
        governments.append(
            {
                "phid": mini.LeaderPHID,
                "pm": pms[mini.LeaderPHID]["DisplayName"],
                "start_date": mini.DateStart.date().isoformat(),
                "party": mini.party,
            }
        )
    else:
        current_end = mini.DateEnd.date().isoformat()
        current_party = mini.party
        current_pm = mini.LeaderPHID
import datetime

df_gov = pd.DataFrame(governments)
df_gov["start_date"] = pd.to_datetime(df_gov["start_date"])
df_gov["end_date"] = pd.to_datetime(df_gov["end_date"])
df_gov.fillna({"end_date": datetime.datetime.now()}, inplace=True)
df_gov["days_in_office"] = df_gov["end_date"] - df_gov["start_date"]
df_gov["days_in_office"] = df_gov["days_in_office"].dt.days
df_gov.style.bar(subset=["days_in_office"], color="#d65f5f").format(
    {"start_date": "{:%Y-%m-%d}", "end_date": "{:%Y-%m-%d}"}
).hide()

def find_party_by_date(df, date):
    govs = df.loc[(df["start_date"] <= date) & (df["end_date"] >= date)]
    if not govs.empty:
        return govs.iloc[0].to_dict()["party"]

Parliaments

Endpoint: https://handbookapi.aph.gov.au/api/StatisticalInformation/Parliaments

Parliaments start after an election and end when the House of Representatives is dissolved (or the 3 year term expires) and a new election is called. Parliaments are numbered consecutively, starting at 1.

Parliaments can be broken up into sessions. Sessions end when the House of Representatives is dissolved or the parliament is prorogued. There’s no fixed limit on the length of sessions, or on how many sessions comprise a Parliament. The House of Representatives Practice notes that:

It is now the usual practice for Parliaments (the 44th Parliament excepted) to consist of one session only. However, in the past the number and duration of sessions have varied considerably…

A session can be prorogued multiple times as the date for the resumption of Parliament is pushed further off into the future. Sometimes the Parliament does not resume and is instead dissolved. As a result, a session can end some time before parliament is officially dissolved.

Within each session are a number of sitting periods (currently there are Autumn, Winter, and Spring periods), that comprise a series of sitting days.

For more information see:

  • Infosheet 25 - Prorogation and dissolution
  • Guide to procedures – sittings of the House
  • House of Representatives Practice – A Session

These practices are reflected in the different dates returned by the Parliaments endpoint. Each parliament has:

  • DateElection – the date of the election preceding the parliament (the Constitution requires that parliament must be summoned to meet not later than 30 days after the day appointed for the return of the election writs)
  • DateDissolution – the date on which the parliament was dissolved (a new election is triggered)

Each session has a DateOpening and a DateClosing, but can also have multiple Prorogations, each with a DateProrogued.
